## App Name
* Smart Pantry Manager

## App Description:

* My smart pantry manager is an android application using Java, program language which allows users to add ingredients to the pantry that displays the quantity and the expiry dates. 
* The application displays about 12 different recipes with instructions 

## Database Used and why?

* Database I used was SQLite 
* I used SQLite because it easily integrated into Android Studio as it is bulit in and doesn't require a database server. 
* It also stores the data locally on the device.

## Setup

### How to install or run the Physical Device/Emulator

##### How to connect with emulator:
1.  Download or clone the repository
2.  Open the projects in Android Studio
3.  Give Gradle time to synchronize.
4.  Connect with an emulator using Pixel 6(Android 15.0).
5.  Run the application

##### How to connect with physical device:
###### Android Device using USB Cable:
1. Enable developer options on your phone:
   * Settings -> About Phone(or About Device) -> Software Information -> Build Number -> Tap Build Number 7 times consecutively(you'll see this message: "You are a developer!"").
2. Turn on USB Debugging 
    * Settings -> Developer Options -> turn on toggle 
    * Scroll down and turn on USB Debugging
3. Connect to the PC via USB 
    * Using a high-quality USB Cable and select File Transfer(MTP) as the USB method to connect your phone to your computer/laptop.
    * Choose "Always allow from this computer" and press Allow when prompted to permit USB debugging. 
4. Then run your app in Android Studio
